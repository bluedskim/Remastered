Remastered is built on open-source software. We are grateful to the projects and communities below.

Remastered itself is released under the MIT License. The mastering pipeline includes matchering (GPLv3); if you deploy or redistribute Remastered, please respect that license.

Core / pipeline

  • matchering — reference-based audio mastering (GPLv3)
  • yt-dlp — YouTube audio download
  • ffmpeg — encode, decode, and render audio
  • libsndfile — audio file I/O (system dependency in Docker images)

App / web stack

  • Click, FastAPI, Uvicorn, Jinja2, Pydantic / pydantic-settings
  • google-api-python-client, google-auth-httplib2, google-auth-oauthlib (YouTube upload CLI)
  • PyJWT, bcrypt, itsdangerous, cryptography, python-multipart, httpx (web auth and helpers)
  • Hatchling (build)
  • htmx (loaded from unpkg in the site template)
  • Pretendard font (CDN in the site template)
